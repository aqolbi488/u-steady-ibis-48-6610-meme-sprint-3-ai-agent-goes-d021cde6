A procedurally drawn meme about an AI agent that has gone rogue: asked to summarize a meeting, it attends as its human, gets promoted, and fires them. A Node 22 program using only the standard library draws every pixel itself — its own PNG encoder and 5x7 pixel font — and writes a deterministic 1024x1024 image to /output/entry.png.

## Run it

```sh
node main.ts
```
